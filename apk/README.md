# GigaTV — приложение для Android TV (Xiaomi HyperOS 2)

Нативное приложение для просмотра фильмов на телевизоре: каталог с постерами и
описаниями из TMDB, поиск, собственная медиатека из ваших плейлистов и
встроенный плеер (MP4/MKV, HLS, DASH).

**Важно:** приложение — это плеер и каталог. Оно воспроизводит только те
источники, которые вы добавили сами. Добавляйте только контент, на который у
вас есть права (собственные файлы, купленный контент, открытые лицензии).

## Стек

- Kotlin + Jetpack Compose for TV (`androidx.tv:tv-material`)
- Media3 / ExoPlayer (видео: MP4, HLS `.m3u8`, DASH `.mpd`)
- Retrofit + kotlinx.serialization (TMDB API), Coil (картинки), DataStore (настройки)
- minSdk 24 (Android 7+), targetSdk 34

## Сборка

Нужен **JDK 17+** (плагин Android Gradle 8.5.2 не запустится на Java 8) и
**Android SDK** с `platforms;android-34` и `build-tools;34.0.0`.

Путь к SDK задаётся в `local.properties` — файл машинозависимый и в репозиторий
не коммитится, так что на новой машине его надо поправить под себя:

```properties
sdk.dir=C\:\\Android\\Sdk
```

Если SDK ещё нет, хватит command-line tools без Android Studio:

```powershell
# распаковать в <SDK>\cmdline-tools\latest, затем:
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.19.10-hotspot"
C:\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat --sdk_root=C:\Android\Sdk `
    "platform-tools" "platforms;android-34" "build-tools;34.0.0"
```

```powershell
.\gradlew.bat assembleDebug
```

Готовый APK: `app\build\outputs\apk\debug\app-debug.apk`

Релизная сборка (нужна подпись своим ключом):

```powershell
keytool -genkeypair -v -keystore gigatv.keystore -alias gigatv -keyalg RSA -keysize 2048 -validity 10000
.\gradlew.bat assembleRelease
```

## Установка на Xiaomi TV (HyperOS 2 / Android TV)

### Способ 1 — ADB по сети (рекомендую)

1. На телевизоре: **Настройки → О телевизоре** → несколько раз нажмите на
   «Версия ОС» (или «Build»), пока не появится «Вы стали разработчиком».
2. **Настройки → Для разработчиков** → включите **Отладка по USB** и
   **Отладка по Wi-Fi / ADB по сети** (название зависит от прошивки).
3. Узнайте IP телевизора: **Настройки → Сеть**.
4. На компьютере (телевизор и ПК в одной сети):

```powershell
$env:PATH += ";$env:LOCALAPPDATA\Android\Sdk\platform-tools"
adb connect <IP-телевизора>:5555
# подтвердите запрос на экране телевизора
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

### Способ 2 — через флешку или «Send files to TV»

1. Скопируйте `app-debug.apk` на флешку (или перешлите приложением
   *Send files to TV*).
2. На телевизоре откройте файловый менеджер, выберите APK.
3. Разрешите установку из неизвестных источников, когда система спросит.

## Каталог фильмов: TMDB и Cinemeta

Источники каталога (постеры, описания, поиск) в текущей сборке:

- **TMDB** — официальное открытое API, нужен бесплатный ключ, см. ниже.
- **Cinemeta** — без ключа, используется автоматически, если ключа TMDB нет.

Поддержки Kinopoisk.dev в коде больше нет — репозиторий и модели удалены,
`KP_API_KEY` ничего не делает. Если будете возвращать, ключ задавайте на экране
«Настройки», а не в сборке.

Переключатель активного каталога и ключ API — на экране «Настройки».
На экране «Источники» живут только плейлисты.

## Ключ TMDB (каталог фильмов)

1. Зарегистрируйтесь на [themoviedb.org](https://www.themoviedb.org/),
   в настройках профиля откройте раздел **API** и получите бесплатный ключ (v3).
2. Введите ключ в приложении: **Настройки → Ключ TMDB API**.

Прописать `TMDB_API_KEY=...` в `local.properties` тоже можно, но тогда ключ
попадёт в APK, а оттуда достаётся из dex за минуту. Для личной сборки это
терпимо; делиться таким APK нельзя.

Без ключа работает медиатека из плейлистов; каталог и поиск TMDB отключены.

> В некоторых сетях `api.themoviedb.org` может быть недоступен. Базовые адреса
> API и картинок вынесены в `TmdbConst`
> (`app/src/main/java/com/artem/gigatv/data/tmdb/TmdbRepository.kt`) — их можно
> заменить на адрес своего прокси/зеркала.

## Свои плейлисты

Плейлист — это JSON-файл, доступный по URL (можно хостить на GitHub Gist,
своём сервере, NAS и т.п.). Добавляется на экране **Источники**.

```json
{
  "name": "Моя коллекция",
  "items": [
    {
      "title": "Название фильма",
      "url": "https://example.com/video.mp4",
      "poster": "https://example.com/poster.jpg",
      "year": 2020,
      "description": "Описание фильма",
      "tmdbId": 123
    }
  ]
}
```

- `url` — прямая ссылка на MP4/MKV, HLS-поток (`.m3u8`) или DASH (`.mpd`).
- `poster`, `year`, `description` — необязательные.
- `tmdbId` — необязателен; если указан, фильм из каталога TMDB получает кнопку
  «Смотреть» с вашим источником (связка каталог → ваш файл).
- `isSeries` — `true` для сериала, `false` для фильма (по умолчанию). Тип учитывается
  вместе с `tmdbId`, поскольку ID фильмов и сериалов TMDB пересекаются.

## Торренты (TorrServe)

Экран «Торренты» управляет сервером [TorrServe](https://github.com/YouROK/TorrServer)
по REST: приложение добавляет раздачу, ждёт метаданные и играет HTTP-поток,
который отдаёт сервер. Само приложение ничего не качает и не раздаёт.

Адрес сервера задаётся там же, на экране «Торренты» (по умолчанию
`http://127.0.0.1:8090` — TorrServe, запущенный на самом телевизоре).
Для проверки есть кнопки с раздачами Internet Archive под CC-BY.

Учтите: при просмотре торрента вы одновременно его раздаёте. Добавляйте только
раздачи, на которые у вас есть права.

## Обновление приложения

Магазина у сайдлоад-сборки нет, поэтому приложение проверяет обновления само:
на экране «Настройки» указывается адрес JSON-файла, а рядом — кнопка проверки.

```json
{
  "versionCode": 7,
  "versionName": "0.4.2",
  "url": "https://example.com/GigaTV-0.4.2-release.apk",
  "notes": "что нового",
  "sha256": "необязательно, hex-хеш APK"
}
```

Требования, без которых обновление будет отклонено:

- **только `https://`** — и у самого JSON, и у ссылки на APK;
- **та же подпись**, что у установленного приложения, и **то же имя пакета** —
  то есть APK должен быть подписан вашим keystore (см. раздел о подписи);
- версия в APK должна быть новее установленной;
- если в JSON указан `sha256`, он должен сойтись.

Проверка подписи здесь — главное: без неё подменённый по пути ответ сервера
поставил бы на телевизор произвольное приложение.

## Структура кода

```
app/src/main/java/com/artem/gigatv/
├── KinoApp.kt                  # Application + контейнер зависимостей (AppContainer)
├── MainActivity.kt             # Навигация и боковое меню
├── data/
│   ├── SettingsRepository.kt   # DataStore: ключи API, плейлисты, адрес TorrServe
│   ├── catalog/                # Фасад каталога над TMDB и Cinemeta (CatalogMovie)
│   ├── cinemeta/               # Каталог без ключа (v3-cinemeta.strem.io)
│   ├── jacred/                 # Поиск раздач по базе русских трекеров
│   ├── remote/                 # WebSocket-сервер для приложения-пульта
│   ├── update/                 # Проверка и установка обновления
│   ├── tmdb/                   # TMDB API (Retrofit), репозиторий, кэш
│   ├── playlist/               # Модели плейлистов, загрузка по URL, демо
│   ├── favorites/              # Избранное
│   ├── history/                # История и позиции просмотра («Продолжить»)
│   └── torrserve/              # REST-клиент TorrServe
└── ui/
    ├── theme/                  # Тёмная TV-тема
    ├── components/             # Карточка фильма, кнопка, текстовое поле
    ├── home/                   # Главный экран: «Продолжить», плейлисты, каталог
    ├── categories/             # Подборки по жанрам
    ├── details/                # Экран фильма (каталог и локальный)
    ├── player/                 # Плеер Media3/ExoPlayer
    ├── search/                 # Поиск по медиатеке и каталогу
    ├── favorites/              # Экран избранного
    ├── torrents/               # Раздачи и адрес TorrServe
    ├── sources/                # Плейлисты
    └── settings/               # Ключи API, выбор каталога, демо-контент
```
